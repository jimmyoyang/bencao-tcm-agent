- Node 测试 86/86，Python 测试 3/3，构建成功。

- 清除自有 API 后输入框 Key 长度为零；清除全部数据后状态恢复 POPO。
- 390px iframe 验证手机布局及键盘操作，保存手机设置截图。桌面设置可打开/关闭。
- 代码复审发现的错误终止事件、连接误报、清除遗漏、无超时和隐私说明问题已修复，复审无重要遗留项。

BYOK 使用虚构凭据和本机模拟服务，没有复用聊天中发送的真实 Key。不能据此保证任意中转站都支持发布域名的 CORS、所选模型参数或结构化输出。真实服务应通过页面的测试连接验证；该测试只验证连通与正文解析，正式健康回答仍需要通过现有 RAG 校验。
