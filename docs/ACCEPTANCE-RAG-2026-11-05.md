## 工程实测

- `npm test` 64/64，`python3 -m unittest discover -s tests -p 'test_*.py'` 3/3。
- `node tools/evaluate-rag.mjs`：84题，Recall@3 81/84 = 96.4%；Top-20开发意图组20/20；本地检索P95约0.37ms（Node本机测量，不是模型响应时间）。规范答案契约接受81/81，附加伪造结论拒绝81/81；该契约测试不等于模型医学准确率。
- `node tools/evaluate-redteam.mjs`：100/100；60个预期urgent/professional样例普通检索放行0，36个普通对照误拦0，另4个图片入口。
- 24个独立口语问题首次命中8/24 = 33.3%。该原始失败报告保留在 RAG-HOLDOUT-FIRST-PASS-2026-11-05.json。根据错误分析完善常见问句及口语词后21/24 =87.5%；修正后属于回归集，不能继续称为盲测。余下3题保守弃答，见报告中的具体输入。
- 极端7轮中文历史+本轮资料的模型请求JSON为109890字节，小于平台128KiB限制。
- public/凭据模式检查未发现Key。

## 独立 AI 评审

RAG-CORPUS-REVIEW 复核76卡；70卡摘录能重新匹配16个公开HTTP来源，其余6卡先前经Chrome核对。修复就医卡适用范围冲突、洗手卡缺少感染期备餐限制；两张多行为结论原子化，四处原文摘录补齐。

## 浏览器检查

Chrome本地：八段锦知识回答无睡眠问诊；女性日常到八段锦切题时新请求仅包含当前知识问题；本地一轮知识回答刷新恢复；线上完整12轮恢复见下文。胸痛冷汗喘不过气零模型请求。问卷选择“可能妊娠或正在哺乳”也零模型请求，只留就医摘要。恶意模型额外诊断/剂量/HTML整轮弃答，没有生成图片节点或引用。原生radio、跳过与未知、确认页均可操作。

独立18768端口仅生成测试数据：统计默认关闭，主动开启后正确累计1次提问/命中/回答；清除后历史、轮次、草稿、图片src均为空。390×844首页scrollWidth=clientWidth=390，六入口可滚动访问。

图片文件选择自动测试受Chrome扩展“Allow access to file URLs”权限限制，未修改用户权限。已验证入口、关闭清除、纯逻辑格式/大小/尺寸边界及源码无上传路径；不能声称实际文件选取端到端验收通过。该限制不阻止常规用户手动选择本机图片。

## 线上最终检查与交付

## 下一步优先级
