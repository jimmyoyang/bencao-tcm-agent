# 日常困扰梳理与睡眠建议 Implementation Plan

> **For agentic workers:** Execute inline with executing-plans; the user has approved the positioning, priorities, implementation and testing. No additional approval gate is needed.

**Goal:** 完成「描述日常困扰 → 补充关键信息 → 核对阶段小结 → 有依据的建议 → 记录反馈」的可用体验，重点验证睡眠场景。

**Architecture:** 保留原生静态页面和现有历史存储。新增 care.mjs 管理问诊字段、可信资料及用户确认数据；app.js 负责复用弹窗与结果卡片。模型每次仍只调用一次，精选资料随上下文提供，界面明确并非实时搜索。来源链接只能来自已核对的白名单。

**Tech Stack:** 原生 HTML/CSS/ES Modules、Node test、POPO 模型 SDK。

## 已确定范围

- 睡眠、疲惫、消化按主诉提供不同的可跳过问题，既有结构化答案不重复采集；确认后作为新轮次进入历史。
- 睡眠资料来自已核对的国家卫健委、北京天坛医院科普、NHS。仅显示模型实际引用且属于本轮资料的出处；未有出处时明确说明，禁止生成链接。
- 日常建议包含中医导引与放松选项，区分科普与治疗证据，不将八段锦、食物或穴位包装成确切疗效。
- 下一步卡片提供「补充情况」「睡眠日常建议」「记录今日感受」「就医摘要」。急症优先，隐藏调养与记录卡片。
- 用户可主动保存、修改或清除日常偏好，明确同一浏览器后续问答会使用；不自动跨会话记住症状或推测。
- 原历史、导出、停止重试、首页往返不回退。新增确认数据与引用来源随每轮保留；旧数据无需迁移。
- 女性周期、图像识别、实时搜索与视频聚合继续列为后续，不在本次发布中声称已实现。
